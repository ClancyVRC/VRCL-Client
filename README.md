## What is VRCL Client?

**VRCL** stands for **VRChat Launcher**. VRCL Client is a Windows app that makes it easier to launch, manage, and customize your VRChat sessions.

## Features

### 🎮 VRChat Controls
- Start, restart, and close VRChat in **VR mode**.
- Launch and manage VRChat in **Desktop mode** without starting SteamVR.
- See your current session activity.

### 🥽 PCVR Support
- Detect SteamVR, VRChat, and supported Meta / Quest PCVR software.
- Use optional Oculus startup and ASW controls.

### 🎨 Customization
- Choose themes, colors, and available animated effects.
- Customize fonts and other experimental options.

### 💬 Discord Activity
- Show VRCL activity through Discord Rich Presence.
- Control whether your status is visible.

### ⌨️ Keybinds & Tray
- Set keyboard shortcuts for supported actions.
- Use the system tray for quick access to VRCL and session controls.

### 🔄 Updates & App Management
- Check for the latest Beta or Full release.
- Roll back to the previous available version.
- Keep personal Data when updating.
- Install or uninstall VRCL.

### ⚙️ Setup & Support
- Complete first-launch setup and review detected app paths.
- Open the GitHub Page or send feedback from App Information.

## Your VRCL Data

Your settings and personal app data are stored in VRCL's Data folder and account-specific locations. The updater is designed to preserve the Data folder when replacing application files.

For details about local files, GitHub update checks, and optional Discord Activity, see the [Privacy Statement](PRIVACY.md).
